# Лабораторна №9. Пояснення для захисту

## Що було обов’язковим

На першій сторінці Lab9_WP_HTML_JS_2026.pdf задано створення власної медіабібліотеки. Прямо обов’язковими названо audio, video та source. Також потрібне меню бібліотеки з використанням тегів форм. Наповнення студент обирає самостійно. Окремого завдання для варіанта 5 немає, проєкт продовжує мій попередній сайт.

У переліку теорії є embed, object, param, iframe, noembed, figure, figcaption. Список теорії ширший за прямо обов’язкові теги завдання. Figure і figcaption використано для програвачів. Приклади embed, object, iframe, param доступні на успадкованій сторінці SVG. Noembed - застарілий елемент.

## Де й що показати

1. Відкрити `media.html` у браузері через PyCharm або «Медіабібліотеку» у верхньому меню.
2. У розділі «Аудіобібліотека» вибрати «Сигнал готовності» й натиснути «Відтворити аудіо».
3. Вибрати «Послідовність частот», запустити. Підпис і посилання завантаження змінюються.
4. У розділі «Відеобібліотека» показати «Переміщення фігур», потім «Обертання та масштаб».
5. Запустити один програвач під час іншого. Попередній переходить на паузу.
6. Натиснути «Зупинити все». Обидва часи повертаються на початок.
7. У HTML показати audio, video, source, form, select, option і button. У JS показати зміну source.src, load, play, pause та currentTime.

## Що означають теги

| Тег | Значення |
| --- | --- |
| audio | Звуковий програвач. |
| video | Відеопрогравач. |
| source | Варіант джерела файлу для програвача. |
| form | Об’єднує елементи меню. |
| select | Список вибору запису. |
| option | Один пункт списку. |
| label | Підпис, пов’язаний із полем. |
| button | Кнопка запуску дії. |
| figure | Група програвача та підпису. |
| figcaption | Підпис до медіаматеріалу. |

Новими для цього проєкту є audio, video та source. Figure і figcaption уже використовувалися у №6. У №9 ці елементи формують бібліотеку з перемиканням записів.

`controls` додає стандартну панель відтворення. `preload="metadata"` просить спочатку отримати метадані, наприклад тривалість. `poster` задає обкладинку відео. `playsinline` дозволяє показувати відео всередині сторінки на сумісних мобільних пристроях. `type` у source задає MIME-тип, наприклад audio/mpeg, video/mp4, video/webm. `src` - шлях до файлу.

## Як працює меню

Для audio та video є окремі форми. Коли користувач змінює select, подія change знаходить вибраний запис у масиві налаштувань. Скрипт змінює source.src, підпис, адресу завантаження та постер відео, потім викликає load.

Кнопка «Відтворити» обробляє submit. PreventDefault скасовує звичайне надсилання форми, play починає відтворення. Play повертає Promise, тому помилка обробляється через try/catch з повідомленням на сторінці.

Обробник події play призупиняє інший програвач. Для спільної зупинки викликаються pause та currentTime = 0. Так реалізовано поведінку з прикладу методички.

## Про матеріали

Аудіо - два власні синтезовані сигнали тривалістю приблизно 1.59 і 3.18 с. Відео - два власні ролики по 4 с із фігурами варіанта 5. Вони мають лише відеодоріжку. MP4 містить H.264, WebM - VP9. Браузер обирає підтримуване джерело з source.

Матеріали зберігаються в assets/media, тому працюють без зовнішніх відеосервісів. Генератор у scripts/build_media.py використовує Python, Pillow і ffmpeg. Для самого перегляду встановлювати ці інструменти не потрібно.
